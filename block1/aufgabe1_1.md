# Auftrag 1.1: NIST-Definition von Cloud Computing

Bearbeiten Sie die folgenden Fragen in der Gruppe. Konsultieren Sie für die Beantwortung den NIST-Standard (NIST SP 800-145). Notieren Sie Ihre Antworten stichwortartig.

## Wie wird der Begriff Cloud definiert?

- Modell für bequemen, jederzeitigen Netzwerkzugriff nach Bedarf
- auf einen gemeinsam genutzten Pool konfigurierbarer IT-Ressourcen (Netzwerke, Server, Speicher, Anwendungen, Dienste)
- Ressourcen schnell bereitstellbar und wieder freigebbar
- mit minimalem Verwaltungsaufwand bzw. ohne Interaktion mit dem Anbieter

## Welches sind die 5 Merkmale einer Cloud?

- **On-Demand Self-Service:** Kunde bezieht Ressourcen selbständig, ohne Kontakt zum Anbieter
- **Broad Network Access:** Zugriff über das Netzwerk mit Standardgeräten (Laptop, Smartphone, Tablet)
- **Resource Pooling:** Ressourcen werden mehreren Kunden gemeinsam bereitgestellt (Multi-Tenancy), Standort für Kunden meist nicht genau bekannt
- **Rapid Elasticity:** Ressourcen schnell hoch- und herunterskalierbar, wirken für den Kunden unbegrenzt
- **Measured Service:** Nutzung wird gemessen, überwacht und verrechnet (Pay-per-Use)

## Welche Cloud Deployment Modelle kennen Sie?

- **Private Cloud:** exklusiv für eine Organisation
- **Community Cloud:** gemeinsam für eine Gruppe von Organisationen mit ähnlichen Anforderungen (z.B. Behörden)
- **Public Cloud:** öffentlich für alle zugänglich, betrieben von einem Anbieter (z.B. AWS, Azure)
- **Hybrid Cloud:** Kombination aus zwei oder mehr Modellen, verbunden durch Technologien zur Daten- und Anwendungsportabilität

## Was sind Cloud Service Modelle?

- **IaaS (Infrastructure as a Service):** Kunde erhält Rechenleistung, Speicher, Netzwerk; verwaltet Betriebssystem und Anwendungen selbst (z.B. AWS EC2)
- **PaaS (Platform as a Service):** Kunde erhält Plattform zum Entwickeln und Betreiben eigener Anwendungen; Infrastruktur und OS verwaltet der Anbieter (z.B. Heroku, Azure App Service)
- **SaaS (Software as a Service):** Kunde nutzt fertige Anwendung über Browser oder App; Anbieter verwaltet alles (z.B. Microsoft 365, Gmail)

## Welcher ökonomische Effekt bewirkt, dass die Kosten pro Recheneinheit bei Cloud-Anbietern durch das massenhafte Bereitstellen von Kapazitäten kontinuierlich sinken?

- Skaleneffekte (Economies of Scale)
- Fixkosten (Rechenzentren, Personal, Energie, Hardware-Einkauf) verteilen sich auf sehr viele Einheiten
- Grosseinkauf senkt Hardwarepreise, hohe Auslastung durch Resource Pooling
- Folge: Kosten pro Recheneinheit sinken mit wachsender Menge
